Qué demuestra este proyecto

Operaciones CRUD

Registro, lectura, actualización, eliminación y búsqueda de personas desde una interfaz adaptable.

  • UUID como identificador interno.
  • Tipo y número de identificación, nombres y apellidos.
  • Correo único, teléfono, dirección y username generado.
  • Foto de perfil almacenada de forma privada.
⌘

Arquitectura y seguridad

El cliente web consume la API de Supabase, que comunica la aplicación con PostgreSQL.

  • Supabase Auth gestiona las cuentas y contraseñas.
  • PostgreSQL persiste los registros.
  • Storage privado guarda las fotos.
  • RLS y el rol admin restringen las operaciones.

CRUD de personas

Estudiante: Angela

Docente: Hermes Acevedo

Programa: Ingeniería Informática

CRUD de ID UUID, tipo y número de identificación, nombres, apellidos, correo, teléfono, dirección, username autogenerado y foto.

  • BaaS y API: Supabase conecta PostgreSQL con la interfaz web.
  • Autenticación: Supabase Auth administra las contraseñas; no se guardan en la tabla de personas.
  • Fotos: bucket privado de Supabase Storage; la tabla conserva la ruta.
  • Seguridad: las operaciones sobre registros reales requieren acceso autorizado.
  • Frontend web adaptable a celulares y computadores.
